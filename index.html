QvPalette VPM

VRChat Creator Companion（VCC）用の、パッケージ一覧です。

VCC に追加する

ボタンが効かないときは、VCC の Settings > Packages > Add Repository に、次の URL を貼ってください。

https://yakigura.github.io/vpm-qvpalette/index.json

一覧を追加しただけでは、パッケージは入りません。プロジェクトの Manage Project で、使いたいものを選んで追加します。ベータ版は、VCC の設定で、プレリリース版を表示すると選べます。

ご注意

QvPalette には、QvPen（net.ureishi.qvpen 3.3.15 以上 3.4.0 未満）が必要です。QvPen は、この一覧にはありません。先に導入してください。

新しい版が出ると、VCC の Manage Project に、更新できる、と出ます。以前の版も、VCC のバージョン選択から選べます。
