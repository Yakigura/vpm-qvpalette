VRChat Creator Companion（VCC）用の、パッケージ一覧です。

VCC に追加する

ボタンが効かないときは、VCC の Settings > Packages > Add Repository に、次の URL を貼ってください。

https://yakigura.github.io/vpm-qvpalette/index.json

一覧を追加しただけでは、パッケージは入りません。プロジェクトの Manage Project で、使いたいものを選んで追加します。

パッケージ

QvPalette 1.0.1

QvPen の非公式拡張。ペン 1 本で最大 4096 のインクを使用できる QvPen 拡張ツール。

説明 ・ 更新履歴 ・ 利用規約

自動で入る部品

次のものは、上のパッケージと一緒に入ります。単独で入れる必要はありません。

  • QvInkPreview 1.0.0 — QvPen の各ペンの後ろに、現在のインクと同じマテリアル・色・太さの短い線を表示する VPM パッケージ。

ご注意

QvPalette には、QvPen（net.ureishi.qvpen 3.3.15 以上 3.4.0 未満）が必要です。QvPen は、この一覧にはありません。先に導入してください。

新しい版が出ると、VCC の Manage Project に、更新できる、と出ます。以前の版も、VCC のバージョン選択から選べます。

Packages

QvPalette 1.0.1

Unofficial QvPen extension. Use up to 4096 inks with a single pen.

Documentation ・ Changelog ・ Terms of use

Installed automatically

These come along with the packages above. You do not need to install them separately.

  • QvInkPreview 1.0.0 — Shows a short line behind each QvPen pen, with the same material, color and width as the current ink.

Notes

QvPalette requires QvPen (net.ureishi.qvpen 3.3.15 or later, below 3.4.0). QvPen is not in this listing; install it first.

When a new version is released, VCC shows an update in Manage Project. Earlier versions can still be chosen from the version selector in VCC.
